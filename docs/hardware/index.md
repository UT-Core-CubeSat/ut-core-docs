# Electrical Hardware

UT-CORE’s electrical hardware features several boards that communicate with each-other via the CAN protocol.

## Main Boards

The various programmable boards used for the cubesat.

- **[CDH Board](/hardware/boards/cdh)** — Command & Data Handling
- **[EPS Board](/hardware/boards/eps)** — Electrical Power System
- **[Solar Conglomerator](/hardware/boards/solar)** — Solar Conglomerator
- **[ADCS Board](/hardware/boards/adcs)** — Attitude Determination & Control
- **[COMMS Board](/hardware/boards/comms)** — Communications
- **[GNSS Board](/hardware/boards/gnss)** — Global navigation and Satellite System
- **[Motor Board](/hardware/boards/motor)** — Motors

## Other

- **[MCU Block](/hardware/mcu)** - Modular design that the rest of the boards are based upon.
- **[Solar Boards](/hardware/solar)** - Solar cells & magnetorquer
